## Too few results? [#too-few-results]

1. Remove individual filters with **×**, or choose **Reset all** to start again.
2. Choose a longer time period. There may be more offers next week than today.
3. Try a shorter search term or a different word, such as **music** instead of a specific band name.
4. Check the spelling of the town or venue. Try a nearby town or a larger radius.
5. Remove an age or price filter. Not every event has these details.

A search without results does not necessarily mean that nothing is happening. The event may not have been added to kulturbytes yet.

## Too many results? [#too-many-results]

Start with a time period and a place. Then add a category or event type. For example, select the weekend, Flensburg and concerts.

Change one option at a time. This makes it easier to see which selection helps you.

## Before you set off [#before-you-go]

Check the event details again, especially the date, venue, registration and ticket information. Follow the organizer's website or ticket link if you need more information.

If something is missing or unclear, use the contact details provided for the event or its organizer.
