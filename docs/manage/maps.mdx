The **map position** shows exactly where your organization or venue is located. This helps visitors find it and supports searches for nearby events.

## Address and map position [#address-and-position]

The **address** gives the street, house number, postal code and town. The **map position** marks the location on the map. Check both: a correct address alone does not tell you whether the map marker is in the right place.

## Check the position [#check-position]

1. Open the map page when editing your organization or venue.
2. Zoom in until you can recognise the building or location.
3. Set the position as accurately as possible on the correct building or site.
4. Check the address as well, then save your changes.

Add details such as “Entrance in the courtyard” as meeting-point information for the event if needed.
