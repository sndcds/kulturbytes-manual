A **space** is a room or area within a venue, such as the main hall or a stage. Create the [venue](/manage/venue-and-space) first, then add its spaces.

## Basic information [#basic-information]

Give the space a name that visitors will recognise, such as **Main Hall**. Add a short description and choose a suitable space type. If known, enter the total capacity and the number of seats.

In the accessibility description, explain practical details such as which entrance to use or where a lift is located.

## Accessibility [#accessibility]

Select the features that actually apply to the space. Check details such as step-free access and accessible toilets before entering them. If something is unclear, check with the venue first.

## Save and use the space [#save-and-use]

Save your changes on each page you edit. You can then select the space when [editing an event](/manage/event-edit#2-where).

Keep the space information up to date. It can be used for many events at the same venue.
