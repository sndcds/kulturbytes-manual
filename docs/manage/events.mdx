An event brings together a description, a venue and one or more dates. Create it once, even if it takes place several times.

## Create an event [#create-event]

1. Open your organization in the Dashboard and go to its events.
2. Choose the option to create a new event.
3. Enter a clear title and describe what visitors can expect.
4. Choose the venue and, if needed, a space.
5. Add at least one date with a start date and time.
6. Add any relevant information about price, tickets, registration and accessibility.
7. Save your entries.

The [event editing guide](/manage/event-edit) explains the individual fields.

## Check publication [#publication]

Saving keeps your changes. The **release status** controls whether the event is a draft, ready for review or released for publication. Check this status before you finish.

Check the description, image, venue and dates before releasing the event. Individual dates can have their own status, for example if one date is cancelled.

## Keep an event up to date [#update-event]

Open the existing event to change its details. For a series with the same description, add further dates instead of creating the whole event again. Check venue and ticket links for each date.

If a date is cancelled or moved, update that date so visitors can see the change.
