**Placeringen på kortet** viser præcist, hvor din organisation eller dit sted ligger. Det hjælper de besøgende med at finde stedet og gør det muligt at søge efter arrangementer i nærheden.

## Adresse og placering på kortet [#address-and-position]

**Adressen** angiver vej, husnummer, postnummer og by. **Placeringen på kortet** markerer stedet på kortet. Tjek begge dele: En korrekt adresse fortæller ikke alene, om markøren er placeret rigtigt.

## Tjek placeringen [#check-position]

1. Åbn kortsiden, når du redigerer din organisation eller dit sted.
2. Zoom ind, indtil du kan genkende bygningen eller stedet.
3. Sæt placeringen så præcist som muligt på den rigtige bygning eller det rigtige område.
4. Tjek også adressen, og gem dine ændringer.

Tilføj om nødvendigt oplysninger som “Indgang i gården” som mødested for arrangementet.
